# Hito 0: Propuesta del Sistema de Mesa de Ayuda

## 1. Descripción del Problema
Diseño e implementación de un sistema de mesa de ayuda en C# para registrar, listar, consultar y gestionar solicitudes de soporte técnico dentro de una organización.

## 2. Propuesta del Modelo
Clase inicial `Ticket` proyectada con atributos para almacenamiento de solicitudes y control de estados.

## 3. Propuesta de Interfaz
Diseño en consola para interactuar con los tickets de manera secuencial mediante un menú interactivo.
